========================================================================
BACKGROUND MUSIC DIRECTORY
========================================================================

Agar aapko Saumya ke liye koi specific gaana ya background music chalana hai
(jaise Doraemon theme acoustic, River Flows In You, ya koi cute Hindi song),
toh:

1. Us MP3 file ko is folder mein copy karein, misaal ke taur par:
   assets/music/doremon-song.mp3

2. Phir script.js ke CONFIG section mein 'customAudioUrl' ko update karein:
   customAudioUrl: "assets/music/doremon-song.mp3"

NOTE:
Agar aap koi MP3 file add nahi bhi karte, toh website ke andar ek built-in
soothing lullaby/music-box sound synthesizer hai jo bina kisi MP3 file ke bhi
automatic aur offline bilkul peaceful aur cute background music play karega!
========================================================================
