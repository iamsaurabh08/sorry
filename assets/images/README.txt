========================================================================
SAUMYA (DOREMON) PHOTO DIRECTORY - HOW TO REPLACE PHOTOS
========================================================================

Apni Doremon (Saumya) ki real photos is folder mein rakhein!

Default photo filenames jo website use kar rahi hai:

1. hero-saumya.jpg  -> Scene 1 Main Hero Portrait (Glowing frame with sparkles)
2. doremon.jpg      -> Gallery Special Polaroid ("Meri Doremon ❤️")
3. saumya-1.jpg     -> Gallery Photo 1 ("Ye wali yaad hai? 😂")
4. saumya-2.jpg     -> Gallery Photo 2 ("Ye moment toh kabhi nahi bhool sakta ❤️")
5. saumya-3.jpg     -> Gallery Photo 3 ("Hamesha aise hi muskurati rehna 🌸")
6. finale-saumya.jpg-> Finale Screen Celebration Photo

NOTE:
- Aap .jpg, .jpeg ya .png use kar sakte hain.
- Agar aap koi aur filename ya extension use karte hain, toh script.js ke
  top par jo CONFIG object hai, wahan images ke paths easily change kar sakte hain!
- Website mein in-built browser photo uploader bhi diya gaya hai jisse aap
  direct screen se bhi photos change kar sakte hain!
